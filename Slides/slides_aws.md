# Course Content

<div style="color: #9ca3af; font-style: italic; font-size: 0.9em; margin-bottom: 1em;">

The AWS Academy Cloud Architecting curriculum, version 3.0. All lab work runs in AWS.

</div>

<div style="display: grid; grid-template-columns: 1fr 1fr; gap: 2.6rem; align-items: start;">
<div style="font-size: 0.88em;">

- 17 modules
- 12 guided labs, plus one optional
- 7 challenge labs on one running case: a cafe that grows from a static website to a scalable, highly available, and serverless architecture
- A capstone: design and deploy a highly available architecture, with written documentation
- Lab environments through AWS Academy, at no cost to students
- Aligned with the AWS Certified Solutions Architect Associate exam guide; the course does not confer the certification

</div>
<div style="font-size: 0.85em;">

| Graphs | network routing |
| Complexity | scaling and cost |
| Finite automata | workflows as state machines |
