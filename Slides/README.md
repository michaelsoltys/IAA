# Slides

Slidev decks for *An Introduction to the Analysis of Algorithms* (4th edition). Each `slides_X.X.md` is the lecture for that section. Figures are in `Figures/` and use relative `./Figures/` paths.

The markdown is readable on GitHub. To present locally:

```bash
cd Slides
npx @slidev/cli slides_3.1.md
```
